# LeetCode Practice

Repo này dùng để lưu quá trình luyện LeetCode của mình bằng Python và SQL.

## Mục tiêu
- Rèn tư duy giải thuật
- Cải thiện kỹ năng giải bài phỏng vấn
- Theo dõi tiến độ học mỗi ngày
- Xây dựng thói quen commit code lên GitHub

## Ngôn ngữ sử dụng
- Python
- SQL

## Chủ đề đang học
- Arrays & Strings
- Hashing
- Two Pointers
- Sliding Window
- Linked Lists
- Stacks & Queues
- Tree & Graphs
- Heap
- Greedy
- Binary Search
- Backtracking
- Dynamic Programming

## Quy ước file
- Python: `python/0001_two_sum.py`
- SQL: `sql/0175_combine_two_tables.sql`

## Cách mình học
1. Làm bài trên LeetCode
2. Viết lại lời giải trong VS Code
3. Ghi chú:
   - Ý tưởng
   - Độ phức tạp
   - Lỗi từng mắc
4. Commit lên GitHub
5. Cuối tuần tổng kết pattern đã học trong thư mục `notes/`
